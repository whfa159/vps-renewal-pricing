## The hidden costs that turn a $3 VPS into a $20 one

A low-cost VPS usually includes the server and little else. Before checkout, confirm these items:

1. **Control panel licence.** cPanel, Plesk and DirectAdmin often cost extra. Evoxt’s plan table does not price a control panel licence.
2. **Backups beyond the weekly copy.** Evoxt includes weekly offsite backup. If your data changes hourly and you need daily backups or snapshots, ask whether that is an add-on.
3. **Extra IPv4 addresses.** Evoxt sells floating IPs. The price is not in the plan table. If you need more than one address, check the add-on cost.
4. **Bandwidth overage.** Evoxt’s plans cap monthly transfer between 250 GB and 5,000 GB. The plan table does not say whether extra transfer is throttled or billed, so confirm the policy if you expect a traffic spike.
5. **Migration.** If you need the provider to move an existing site or server, ask about the cost. Migration is not in the plan table.
6. **Managed support.** If you want a managed WordPress host with staging, plugin updates and phone support, a raw VM plan is the wrong product category. The monthly price will not include that layer.
7. **Refund window.** Evoxt’s plan pages do not list a money-back period. If a refund window is part of your decision, get it confirmed before payment.

The weekly backup and firewall are already in Evoxt’s product description, so those two items are not hidden add-ons. The control panel, extra IPs, migration and bandwidth treatment are the ones to check.
